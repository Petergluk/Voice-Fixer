# Obsidian Voice Fixer Plugin

Это базовая версия плагина Voice Fixer для Obsidian, портированная из Chrome Extension и Web версии. Она позволяет диктовать текст, после чего отправляет аудио в Gemini для транскрипции и исправления текста, а затем вставляет готовый результат прямо в вашу заметку.

## Структура проекта

Плагин написан на TypeScript и использует API Obsidian. Все исходные файлы находятся в папке `src/`.

### Основные файлы исходного кода (`src/`):

- **`main.ts`** — Главный файл плагина. Отвечает за инициализацию, регистрацию команд, добавление иконки в боковую панель (ribbon) и запуск процессов записи. Здесь же находится логика вставки текста в редактор Obsidian и фонового вызова Gemini (при скрытом модальном окне).
- **`settings.ts`** — Логика настроек плагина. Описывает структуру `VoiceFixerSettings` (дефолтные значения, список моделей, API-ключи, битрейт, системный промпт) и создает вкладку настроек (`VoiceFixerSettingTab`) в интерфейсе Obsidian, где пользователь может их редактировать.
- **`audioRecorder.ts`** — Модуль для работы с микрофоном (`MediaRecorder`). Захватывает аудио, нарезает его на chunks, собирает в WebM файл и конвертирует в Base64. Также содержит логику визуализации звука с помощью `AudioContext` и `AnalyserNode` для отображения анимации при записи.
- **`geminiApi.ts`** — Модуль для взаимодействия с Google Gemini API (@google/genai). Осуществляет роутинг по моделям (перебор моделей из `DEFAULT_MODELS`, если основная недоступна или уперлась в лимиты) и отправляет системный промпт вместе с Base64 аудио-файлом для расшифровки.
- **`recordingModal.ts`** — Пользовательский интерфейс (модальное окно), который появляется при старте записи. Отображает таймер, кастомный индикатор уровня звука (анимацию столбиков) и кнопку "Готово". После остановки записи модальное окно закрывается, и управление передается обратно в `main.ts` для обработки в фоне.

### Конфигурационные файлы (в корне):

- **`manifest.json`** — Обязательный файл манифеста для Obsidian. Содержит идентификатор плагина (`id`), название, версию, минимально необходимую версию Obsidian и описание.
- **`package.json`** — Файл конфигурации Node.js. Содержит список зависимостей (`obsidian`, `@google/genai`, `esbuild` и т.д.) и скрипты (например, `npm run build`).
- **`tsconfig.json`** — Настройки TypeScript компилятора, определяющие, как исходный код `src/` будет транспилироваться перед сборкой esbuild'ом.
- **`esbuild.config.mjs`** — Скрипт сборки. Использует esbuild для того, чтобы собрать все TypeScript файлы и зависимости в один бандл `main.js`, который понимает Obsidian.
- **`main.js`** — Скомпилированный бандл плагина, готовый к загрузке в Obsidian.

## Установка и сборка для тестирования

1. Зайдите в эту директорию в терминале:
   ```bash
   cd VoiseFixer4Obsidian
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Соберите плагин:
   ```bash
   npm run build
   ```
   *Это обновит файл `main.js`.*

4. Установка в ваш Obsidian Vault (Хранилище):
   * Откройте папку вашего хранилища Obsidian.
   * Перейдите в `.obsidian/plugins/` (если папки plugins нет, создайте её).
   * Создайте там папку `obsidian-voice-fixer`.
   * Скопируйте туда три файла из этой директории:
     - `main.js`
     - `manifest.json`
   * Перезапустите Obsidian (или обновите плагины в настройках).
   * Включите плагин **Voice Fixer** в настройках "Community plugins".

## Использование
1. Зайдите в настройки плагина в Obsidian и вставьте ваш **Gemini API Key**.
2. В боковой панели (Ribbon) слева появится иконка микрофона 🎤. (Либо можно использовать команду `Start Recording` через Command Palette).
3. Нажмите на иконку чтобы начать запись (в первый раз Obsidian запросит доступ к микрофону). Появится всплывающее окно с таймером и визуализацией голоса.
4. По окончании диктовки нажмите "Готово". Модальное окно закроется, а в статус-баре Obsidian появится индикатор расшифровки.
5. Плагин отправит аудио в Gemini, расшифрует, почистит текст (согласно промпту из настроек) и вставит готовый текст прямо на место курсора в активную заметку, а также скопирует резервную копию текста в буфер обмена.
