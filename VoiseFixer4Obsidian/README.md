# Obsidian Voice Fixer Plugin

Это базовая версия плагина Voice Fixer для Obsidian, портированная из Chrome Extension и Web версии.

## Установка и сборка для тестирования

1. Зайдите в эту директорию в терминале:
   ```bash
   cd obsidian-plugin
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Соберите плагин:
   ```bash
   npm run build
   ```
   *Это создаст файл `main.js`.*

4. Установка в ваш Obsidian Vault (Хранилище):
   * Откройте папку вашего хранилища Obsidian.
   * Перейдите в `.obsidian/plugins/` (если папки plugins нет, создайте её).
   * Создайте там папку `obsidian-voice-fixer`.
   * Скопируйте туда три файла из этой директории:
     - `main.js`
     - `manifest.json`
   * Перезапустите Obsidian (или обновите плагины в настройках).
   * Включите плагин **Voice Fixer** в настройках "Community plugins".

## Использование
1. Зайдите в настройки плагина и вставьте ваш **Gemini API Key**.
2. В боковой панели (Ribbon) слева появится иконка микрофона 🎤.
3. Нажмите на иконку чтобы начать запись (в первый раз Obsidian запросит доступ к микрофону).
4. Нажмите еще раз, чтобы остановить запись. 
5. Плагин отправит аудио в Gemini, расшифрует, почистит текст (согласно промпту из настроек) и вставит готовый текст прямо на место курсора в активную заметку!
