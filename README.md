# Voice Fixer & PuuNote Ecosystem

Этот репозиторий содержит исходный код плагина **Voice Fixer**, который позволяет диктовать текст, отправлять аудио в Gemini для транскрипции и очистки от словесного мусора, после чего вставлять готовый, аккуратно отформатированный результат. 

**Voice Fixer существует в трех версиях**, исходный код которых находится в соответствующих папках:

### 1. Web Версия (PuuNote Plugin)
- **Где лежит:** `src/` (и конкретно `src/plugins/voice-fixer` если он там есть, плюс инфраструктура песочницы).
- **Для чего:** Это версия плагина для веб-приложения PuuNote. В папке `src/` также находится песочница (React + Vite) для удобного тестирования и разработки веб-плагинов в изоляции.
- **Как запустить:** `npm install` и `npm run dev` из корня проекта.

### 2. Obsidian Plugin
- **Где лежит:** `VoiseFixer4Obsidian/`
- **Для чего:** Версия плагина Voice Fixer для интеграции непосредственно в редактор Obsidian. Позволяет диктовать текст прямо в ваши заметки.
- **Как собрать:** Перейдите в папку `VoiseFixer4Obsidian` и выполните `npm run build` (это создаст готовый `main.js` для Obsidian).

### 3. Chrome Extension
- **Где лежит:** `chrome-extension/`
- **Для чего:** Версия плагина в виде браузерного расширения Chrome. Позволяет использовать возможности умной диктовки с ИИ на любых веб-сайтах в интернете (в любых текстовых полях).

## Дополнительная документация

- **`AGENTS.md`**: Глобальные инструкции для AI-ассистентов (какие модели Gemini использовать, какие модели отключены, и правила стилизации UI).
- **`docs/PLUGIN_API.md`**: Документация по Plugin API для веб-песочницы PuuNote.
- **`public/`**: Папка для статики веб-песочницы. Сюда же собираются готовые `.zip` архивы (например, `VoiseFixer4Obsidian.zip`), чтобы их можно было легко скачать через браузер, если разработка ведется в облаке.
